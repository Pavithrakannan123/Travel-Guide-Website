# Travel-Guide-Website
I created a modern and responsive Travel Guide Website using HTML and CSS as part of my front-end web development practice project. The website includes a clean header section with a custom logo, navigation menu, and search bar for easy user interaction.

Travel Guide Website

A modern and responsive Travel Guide Website created using HTML and CSS. This project is designed to help users explore travel destinations, hotels, restaurants, and travel packages through a clean and user-friendly interface.

Features
Responsive webpage design
Custom navigation bar
Search bar for travel exploration
Popular destinations section
Hotels and restaurants section
Attractive travel package cards
Modern UI design with hover effects
Mobile-friendly layout using CSS

Technologies Used
HTML5
CSS3

Project Purpose
The purpose of this project is to improve front-end web development skills by building a real-world travel website layout using only HTML and CSS without any frameworks.

What I Learned
Structuring webpages using HTML
Styling webpages using CSS
Creating responsive layouts
Using Flexbox and positioning
Adding hover effects and animations
Improving UI/UX design skills
